# 🛡️ SentiGuard

Микросервис, который находит персональные и чувствительные данные в тексте на русском и английском
и умеет их замаскировать перед отправкой в LLM (OpenAI, Claude и т.п.), а потом вернуть обратно.

Внутри три слоя:

1. **Natasha** (нейросеть ~30 МБ, CPU): ФИО в любом падеже с нормальной формой, города, организации, адреса.
2. **Российские шаблоны** (`sentiguard/ru.py`): паспорт, СНИЛС, ИНН, ОГРН, карты, счета и др.
   С проверкой контрольных сумм и слов-подсказок рядом («паспорт», «СНИЛС», «ИНН»), чтобы не путать с артикулами.
3. **Microsoft Presidio**: почта, IP, ссылки, IBAN, международные телефоны, английские имена, документы США/Великобритании/Индии/Австралии/Сингапура.

Онлайн: https://datahunter.store/tools/text/sensetive/detect

## Все маркеры

Это полный список: его же отдаёт `GET /entities` (по факту загруженных распознавателей).

### Россия

| Тип | Метка | Что ловит | Как проверяется |
|---|---|---|---|
| `PER` | ФИО | Имя, фамилия, отчество в любом падеже, в т.ч. с маленькой буквы | Natasha; маленькие буквы только если слово есть в словаре имён |
| `PHONE_NUMBER` | ТЕЛЕФОН | +7 / 8 / 7 в любых форматах, 10 цифр с 9 рядом со словом «тел», международные с «+» | шаблон + libphonenumber |
| `RU_PASSPORT` | ПАСПОРТ | Серия и номер: `4510 123456`, `45 10 № 123456` | без слова «паспорт/серия/выдан» рядом не засчитывается |
| `RU_INT_PASSPORT` | ЗАГРАНПАСПОРТ | `75 1234567` | только рядом со словом «загран»/passport |
| `RU_SNILS` | СНИЛС | `112-233-445 95` и 11 цифр подряд | контрольная сумма |
| `RU_INN` | ИНН | ИНН физлица (12) и организации (10) | контрольная сумма |
| `RU_KPP` | КПП | 9 знаков | только рядом со словом «КПП» |
| `RU_OGRN` | ОГРН | ОГРН (13) и ОГРНИП (15) | контрольная сумма |
| `RU_DRIVER_LICENSE` | ВУ | `77 АВ 123456`, `77 12 123456` | рядом «права», «в/у», «водит» |
| `RU_OMS` | ОМС | Полис единого образца, 16 цифр | рядом «полис»/«ОМС» |
| `RU_BIRTH_CERT` | СВИДЕТЕЛЬСТВО | `II-МЮ 654321` | шаблон |
| `RU_MILITARY_ID` | ВОЕННЫЙ_БИЛЕТ | `АК 1234567` | рядом «военный»/«билет» |
| `RU_BANK_ACCOUNT` | СЧЁТ | 20 цифр; счета физлиц 408…, 423… | 408/423 всегда, прочие рядом «р/с», «счёт» |
| `RU_CAR_PLATE` | ГОСНОМЕР | `А123ВС77` | буквы только допустимые на номерах |

| `LOC` | МЕСТО | Город, регион, страна | Natasha |
| `ORG` | ОРГАНИЗАЦИЯ | «ООО Ромашка», «ОВД» | Natasha |

## API

```bash
# найти
curl -X POST http://localhost:8000/analyze -H "Content-Type: application/json" \
  -d '{"text": "Отправь документ Ивану Иванову, паспорт 4510 123456, тел. +7 999 123-45-67"}'
```
```json
[
  {"text": "Ивану Иванову", "normal": "Иван Иванов", "case": "Dat", "start": 17, "end": 30, "type": "PER", "score": 0.85, "source": "natasha"},
  {"text": "4510 123456", "normal": "4510 123456", "case": null, "start": 40, "end": 51, "type": "RU_PASSPORT", "score": 0.95, "source": "regex"},
  {"text": "+7 999 123-45-67", "normal": "+7 999 123-45-67", "case": null, "start": 58, "end": 74, "type": "PHONE_NUMBER", "score": 0.95, "source": "regex"}
]
```

Параметры `/analyze` и `/anonymize`:
- `entities`: список типов, если нужны не все;
- `score_threshold` (по умолчанию 0.4): ниже порога находка отбрасывается;
- `mode` (только `/anonymize`): `tag` → `[ФИО_1]`, `mask` → `*****`, `redact` → удалить.

```bash
# замаскировать перед отправкой в LLM
curl -X POST http://localhost:8000/anonymize -H "Content-Type: application/json" \
  -d '{"text": "Иван Петров, тел. +7 999 123-45-67. Иван Петров придёт завтра."}'
# -> {"text": "[ФИО_1], тел. [ТЕЛЕФОН_1]. [ФИО_1] придёт завтра.", "items": [...], "entities": [...]}

# вернуть исходное в ответ LLM
curl -X POST http://localhost:8000/deanonymize -H "Content-Type: application/json" \
  -d '{"text": "Ответ для [ФИО_1]", "items": [{"placeholder": "[ФИО_1]", "type": "PER", "text": "Иван Петров"}]}'
```

Одинаковые значения получают одну метку, так что LLM видит, что это один человек.
`GET /entities` отдаёт все маркеры, `GET /health` проверяет работу. Документация OpenAPI: `/docs`.

## Запуск

```bash
docker compose up -d --build     # слушает 127.0.0.1:8000
docker compose run --rm sentiguard-nlp python -m pytest -q tests
```

Порт по умолчанию открыт только локально. Наружу сервис выставлять через обратный прокси с авторизацией:
в запросах персональные данные. Сервис ничего не пишет на диск и не логирует тексты.
Память: ~600 МБ на процесс (2 процесса uvicorn). Предел длины текста: `MAX_TEXT_LEN` (100 000 символов).

## Ограничения (честно)

- ФИО одним словом без контекста («Иванов») Natasha иногда не узнаёт; редкие фамилии тоже.
- Адреса без слов «ул.», «проспект», «д.» (просто «Ленина 5») не ловятся.
- Паспорт, ВУ, ОМС, КПП без слова-подсказки рядом не засчитываются, чтобы не путать с номерами заказов.
- Даты без слова «рождения» не маскируются (порог 0.4), иначе закроется любая дата в тексте.
- Presidio-распознаватели других стран работают только на латинице.
